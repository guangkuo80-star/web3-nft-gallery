# Sepolia NFT Gallery

A full-stack Web3 demo — mint and showcase ERC-721 NFTs on **Sepolia testnet**. Built as a portfolio piece for a frontend engineer transitioning into Web3.

> ⚠️ **Testnet only.** Sepolia ETH has no monetary value. Do **not** deploy this contract to mainnet without an audit.

## Tech stack

**Frontend**

- [Next.js 15](https://nextjs.org) (App Router, React Server Components)
- [TypeScript](https://typescriptlang.org) (strict)
- [wagmi v2](https://wagmi.sh) + [viem](https://viem.sh) — type-safe contract reads/writes
- [RainbowKit v2](https://rainbowkit.com) — wallet connect UI (MetaMask / WalletConnect / Coinbase)
- [Tailwind CSS](https://tailwindcss.com)

**Smart contract**

- [Solidity](https://soliditylang.org) `0.8.24`
- [Hardhat](https://hardhat.org) — compile, test, deploy, verify
- [OpenZeppelin Contracts v5](https://openzeppelin.com/contracts) — `ERC721`, `ERC721Enumerable`, `ERC721URIStorage`, `Ownable`, `Pausable`, `ReentrancyGuard`
- [Alchemy](https://alchemy.com) Sepolia RPC
- Metadata hosted on [IPFS](https://ipfs.tech) (Pinata gateway)

## Getting started

### Prerequisites

- Node.js **20.11+** (LTS)
- npm **10+** (or pnpm/yarn — adjust commands)
- A browser wallet (MetaMask recommended)
- Sepolia testnet ETH — grab from [Chainlink Faucet](https://faucets.chain.link/sepolia) or [Alchemy Faucet](https://www.alchemy.com/faucets/ethereum-sepolia)
- An Alchemy account (free) for a Sepolia RPC URL — [dashboard.alchemy.com](https://dashboard.alchemy.com)
- A Reown (WalletConnect) project id (free) — [cloud.reown.com](https://cloud.reown.com)

### 1. Install

```bash
npm install
```

### 2. Configure environment

```bash
cp .env.example .env.local
```

Open `.env.local` and fill in:

| Key | Where to get it |
| --- | --- |
| `SEPOLIA_RPC_URL` | Alchemy dashboard → Create App → Sepolia → copy HTTPS URL |
| `DEPLOYER_PRIVATE_KEY` | MetaMask → Account Details → Export Private Key (**throwaway wallet only!**) |
| `NEXT_PUBLIC_SEPOLIA_RPC_URL` | Same Alchemy URL (browser-facing) |
| `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` | cloud.reown.com → Create Project |
| `ETHERSCAN_API_KEY` | Optional — for auto-verifying on Etherscan |
| `NEXT_PUBLIC_CONTRACT_ADDRESS` | Filled **after** step 4 |

⚠️ **Security rules**

1. `.env.local` is gitignored — **never commit it**.
2. Use a **throwaway** deployer wallet funded with Sepolia ETH only. Never reuse a mainnet key.
3. Never paste your private key into chats, screenshots, or issues.
4. On Vercel, add each key via _Settings → Environment Variables_.

### 3. Compile + test the contract

```bash
npm run compile     # → artifacts/contracts/MyNFT.sol/MyNFT.json
npm test            # → 10+ unit tests should pass
```

### 4. Deploy to Sepolia

```bash
npm run deploy:sepolia
```

Expected output:

```
Deploying MyNFT to "sepolia"
Deployer: 0xAbC…123
Balance : 0.42 ETH
────────────────────────────────────────
✅ MyNFT deployed
   Address  : 0x1234…abcd
   Tx hash  : 0x…
   Explorer : https://sepolia.etherscan.io/address/0x1234…abcd
📝 Wrote lib/deployments/sepolia.json
🔍 Waiting for 5 block confirmations before verifying...
✅ Verified on Etherscan
```

Now **copy the address** into `.env.local`:

```env
NEXT_PUBLIC_CONTRACT_ADDRESS=0x1234...abcd
```

### 5. Run the frontend

```bash
npm run dev
# → http://localhost:3000
```

Click **Connect Wallet**, switch MetaMask to Sepolia, click **Mint**, approve the tx, and your NFT appears in the gallery ~10s later.

## Local development without Sepolia

Prefer to iterate without burning testnet ETH? Run a local Hardhat chain:

```bash

npm run node

# Terminal 2 — deploy to localhost
npm run deploy:local
# → copy printed address into .env.local as NEXT_PUBLIC_CONTRACT_ADDRESS

# Terminal 3 — frontend
npm run dev
```

Import one of the local accounts into MetaMask (chainId 31337, RPC `http://127.0.0.1:8545`, private keys printed by `npm run node`). Each starts with 10 000 ETH.

## Contract highlights

```solidity
uint256 public constant MAX_SUPPLY     = 1000;
uint256 public constant MAX_PER_WALLET = 5;
uint256 public mintPrice = 0.001 ether;

function mint(uint256 quantity)
    external payable nonReentrant whenNotPaused
{
    require(publicMintOpen, "Public mint is closed");
    require(quantity > 0 && quantity <= MAX_PER_WALLET, "Invalid quantity");
    require(totalSupply() + quantity <= MAX_SUPPLY, "Would exceed max supply");
    require(balanceOf(msg.sender) + quantity <= MAX_PER_WALLET, "Exceeds per-wallet cap");
    require(msg.value >= mintPrice * quantity, "Insufficient ETH");
    // … mints + refunds overpayment
}
```

Owner-only: `ownerMint` (airdrop), `setMintPrice`, `setBaseURI`, `togglePublicMint`, `pause`/`unpause`, `withdraw`.

Convenience view for the frontend: `tokensOfOwner(address) → uint256[]`.

## Metadata / IPFS

The contract's `baseURI` points at an IPFS directory whose children are `<tokenId>.json` files. The default URI in `scripts/deploy.js` uses a public demo CID — **replace it with your own** before a real deploy:

1. Create N JSON files (`0.json`, `1.json`, …) following [ERC-721 Metadata schema](https://docs.opensea.io/docs/metadata-standards).
2. Upload the folder to [Pinata](https://pinata.cloud) / [web3.storage](https://web3.storage) / [NFT.Storage](https://nft.storage).
3. Copy the directory CID and set `NFT_BASE_URI=ipfs://<CID>/` in `.env.local` **before** running `deploy:sepolia` (must end with `/`).
4. Or after deploy, call `setBaseURI()` from the owner wallet.

The frontend already resolves `ipfs://…` → `https://ipfs.io/ipfs/…` for image rendering.

## Deploy the frontend to Vercel

### Push to GitHub

```bash
git init
git add .
git commit -m "feat: initial NFT gallery — Sepolia ERC-721 + Next.js frontend"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/web3-nft-gallery.git
git push -u origin main
```

### Import into Vercel

1. https://vercel.com/new → import `web3-nft-gallery`
2. Framework Preset: **Next.js** (auto-detected)
3. Root Directory: `./`
4. **Environment Variables** — add only the `NEXT_PUBLIC_*` keys:
   - `NEXT_PUBLIC_CONTRACT_ADDRESS` = your deployed contract
   - `NEXT_PUBLIC_SEPOLIA_RPC_URL` = your Alchemy URL
   - `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` = your Reown id
   - **DO NOT** add `DEPLOYER_PRIVATE_KEY` or `SEPOLIA_RPC_URL` — Vercel never deploys contracts, only serves the frontend
5. Deploy. First build ≈ 90 s.
6. Every `git push origin main` triggers an auto-deploy.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `Contract not configured` banner on the site | `NEXT_PUBLIC_CONTRACT_ADDRESS` is still zero — set it after deploy, then `npm run dev` again |
| MetaMask stuck on "Switch to Sepolia" | Your wallet is on another network; click the prompt or manually switch |
| `Insufficient funds` on mint | Get Sepolia ETH from the faucet (linked above); faucets are rate-limited |
| Images not loading in the gallery | `baseURI` points to a dead CID or wrong gateway; verify `tokenURI(id)` returns a valid `ipfs://…` and the JSON is reachable via https://ipfs.io/ipfs/… |
| Hardhat: `invalid sender` / `nonce too low` | Your RPC URL is wrong or the deployer key belongs to a different network |
| Vercel build fails with `Module not found: wagmi` | Delete `.next/` and `node_modules/`, commit an updated `package-lock.json`, redeploy |
